# Installing KPI Lab

Download from the [latest release](https://github.com/goliash/kpi-lab/releases/latest).

**Windows.** `KPI-Lab-Setup.exe` installs it; `KPI-Lab-Portable.exe` runs without installing.
The app isn't signed with a paid certificate yet, so Windows may show "Windows protected your PC":
choose **More info › Run anyway**.

**Mac.** `KPI-Lab-mac-arm64.dmg` for Apple chips (M1 and newer), `KPI-Lab-mac-x64.dmg` for Intel.
Open the `.dmg` and drag KPI Lab to Applications. The first time, macOS will say it can't check the
app (it isn't signed with a paid Apple Developer account): open it once, then go to **System
Settings › Privacy & Security** and choose **Open Anyway**.

**Linux.** `KPI-Lab-linux-x86_64.AppImage`: make it executable (right-click › Properties › Allow
executing, or `chmod +x`) and double-click. Or install `KPI-Lab-linux-amd64.deb` on Ubuntu/Debian.

**Phones and other browsers.** Open https://john.goliash.com/kpi-lab and use **File › Install on this
device** (iPhone and iPad: in Safari, Share › Add to Home Screen).
